# Card rules

## One card
- **One concept per card.** The question asks exactly what an exam asks ("Hashimoto thyroiditis: biochemical findings?"), not "Tell me about Hashimoto".
- **1–5 points**, each a short line with **key terms in bold**. More than 5 points means split the card.
- **Memory hook** on the last line: a short phrase, mnemonic or contrast ("Left = lungs, right = rest of body").
- **Picture** only when it helps recall: a diagram, histology slide or table from the student's own slides. Never use watermarked or wrong pictures; check that each picture shows what the card asks.
- **Comparisons:** write points as `A: …; B: …` (or `Pain: A …; B …`) so the designer can turn them into a table.
- **Formulas:** write them with "=" and the arithmetic (`RR = a/(a+b) ÷ c/(c+d)`), so they get a formula box.

## Badges and tags
| Marker | Meaning | Shown as |
|---|---|---|
| `source: "UQ"` | asked in a university or past paper | 🎓 University Q |
| `source: "HY"` | high-yield but not asked yet | ⚡ High-yield |
| `asked: true` (tag `TermAsked`) | asked in this year's term papers | 🔥 Exam favourite |
| `extra: true` | not in the student's own material (textbook) | ✦ Bonus |
| tag `<Subject>_<Chapter>` | chapter, used for filtering | n/a |

## Sources, in order of trust
1. The department's own slides (that's what examiners mark against)
2. The student's notes and model answers
3. The standard textbook, marked ✦ Bonus

When sources disagree, follow the slide, and add the textbook version only if useful ("WHO: …").

## Answer structure for long questions (medicine)
- **Pathology / disease topics:** definition → causes / pathogenesis → morphology (**gross + micro**) → lab / markers → complications.
- **Investigations:** bedside → blood → imaging → scope / biopsy → special test (investigation of choice first).
- **Management:** ABC → conservative → medical → surgical → complications and follow-up.

## Lean deck
- Never cut a past-paper angle.
- Low-yield cards: tag `CUT` and suspend them; never delete.
- Aim for a deck the student can finish once before the exam at about 90 cards a day.
